# 可视化演示与实机测试

## 1. 演示程序 `showcase.py`

五个阶段可切换，既支持窗口实时演示，也能直接导出解说演示片。

| 阶段 | 展示内容 |
|---|---|
| ① 原始输入 | 1024×1024 卫星视频流，10 fps |
| ② 运动掩膜 | 白顶帽 → 帧差（阈值 40）→ 3×3 椭圆闭运算 |
| ③ 运动提案 | 4×4 格子投票 + 轨迹先验 → 6 个 256×256 图块 |
| ④ 图块检测 | 缩放到 320 → INT8 推理 → DFL 解码 → 跨块 NMS |
| ⑤ 跟踪与测速 | 8 状态卡尔曼 + 三级指派 + 光流先验 → km/h |

运行：

```bash
# 窗口实时（无键鼠时用控制文件 ~/ctl 驱动：stage N / next / prev / pause / play / step / auto / quit）
python3 showcase.py --input clip.mp4 --model models/a_p2_nwd_kd320_raw_int8.onnx

# 导出解说演示片（每阶段 50 s + 6 s 解说卡，约 4 分 40 秒）
python3 showcase.py --input clip.mp4 --dump demo.mp4 --dump-per-stage 50 --dump-card 6
```

说明：
- 中文用 PIL 渲染（`cv2.putText` 不支持 CJK，会全部变成问号）；
- 每个阶段开始时重置流水线与播放位置，避免素材循环导致轨迹 ID 累积；
- 无窗口环境下显示走 tkinter（板端 OpenCV 多为 headless 版本）。

## 3. 飞腾派 E2000Q 实机测试矩阵

环境：2 大核 1.8 GHz + 2 小核 1.5 GHz，自动绑大核（cpu2,3），320 输入 INT8，6 图块/帧。

| 用例 | ms/帧 | FPS |
|---|---|---|
| native + CSV | 944.2 | 1.06 |
| native + 视频输出 | 978.6 | 1.02 |
| python + CSV | 1252.4 | 0.80 |
| python + 视频输出 | 1284.2 | 0.78 |
| native + 预热 12 帧 | 946.4 | 1.06 |
| native + 异步 | 946.6 | 1.06 |
| native + 不绑核 | 940.7 | 1.06 |
| 密封门禁（非飞腾派拒绝） | 飞腾派放行，退出码 0 | — |

> 无窗口模式会自动关闭异步外推（否则主循环跑空、统计为 0）；异步仅用于窗口演示。
