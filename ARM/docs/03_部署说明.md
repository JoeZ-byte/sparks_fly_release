# 03 · 部署说明（板端）

## 1. 环境

```bash
sudo apt install -y python3 python3-pip python3-opencv python3-numpy
pip install onnxruntime
```

飞腾派/树莓派均为 aarch64，`onnxruntime` 官方轮子可直接安装。
若板端无法联网，可在 PC 上 `pip download onnxruntime --platform manylinux2014_aarch64` 后拷贝安装。

## 2. 运行

```bash
python3 stream.py --input samples/sample_01_highway_002.mp4 --csv out.csv
python3 stream.py --input samples/sample_01_highway_002.mp4 --max-cells 4 --threads 4
python3 stream.py --input samples/sample_08_tiny_033.mp4 --backend python     # 纯 Python
```

板端建议：`--threads 4`（等于物理核数）、`--max-cells 4~6`、不加 `--show`（无桌面环境）。

## 3. 编译加速库

```bash
cd native
make -j4        # 产物 prebuilt/libsatstream.so
```

随包已提供 aarch64 预编译库（树莓派 4B 验证）。若板端 glibc 较老、加载报
`version GLIBC_2.xx not found`，在板端重新 `make` 一次即可。

## 3.1 绑核（飞腾派自动生效）

飞腾派为 2 大核（cpu2,3 @1.8 GHz）+ 2 小核（cpu0,1 @1.5 GHz）。程序默认：

```
线程数 = 2（config.json 的 threads_phytium）
绑核   = 自动绑大核 cpu2,3（--pin-cores auto）
```

实测 1088.5 → 944.1 ms/帧（+15%）。手动控制：

```bash
python3 stream.py --input in.mp4 --pin-cores 2,3     # 指定核
python3 stream.py --input in.mp4 --pin-cores none    # 不绑
python3 stream.py --input in.mp4 --threads 4         # 覆盖线程数（不建议）
```

树莓派 4B 是 4 个同构 A72，默认不绑核。

## 3.2 密封通道（AES-256-GCM，仅飞腾派触发）

```bash
KEY=$(python3 -c "import os;print(os.urandom(32).hex())")

# 输出密封：轨迹与叠加视频都写 .enc
python3 stream.py --input in.mp4 --seal-csv tracks --seal-video vis --seal-key $KEY

# 输入密封：直接喂 .enc 视频
python3 stream.py --seal-input clips/in.enc --seal-key $KEY --frames 100
```

行为：

- 文件格式 `SFLYSEAL | chunk | {nonce | ciphertext}*`，分块流式，可边解密边解码；
- 明文只写 `/dev/shm`（内存），运行结束覆写并删除；解密输入同样处理；
- **平台门禁**：程序用设备树型号（`Phytium Pi Board`）或 aarch64 大小核容量差判定，
  非飞腾派平台直接拒绝并提示；确需在他处测试用 `--force-seal`；
- 依赖 `pip install cryptography`（板端 OpenSSL 软件实现，实测约 57 MB/s，13 MB 视频加解密 82~191 ms）。

## 4. 显示与检测解耦

同步模式（每帧都检测）在板上只有 1~1.6 FPS。若需要流畅显示，推荐"异步检测 + 卡尔曼外推"：
检测在后台线程按硬件能力跑（约 1.2~1.6 Hz），显示端按 10 fps 输出，中间帧用预测框补齐。
该模式的参数与实现在完整工程中提供；本包默认同步模式，便于阅读与替换。

## 5. 常见问题

**Q1. `ImportError: libGL.so.1`**
无桌面环境时 `opencv-python` 会缺 GL 依赖，改装 `opencv-python-headless`。

**Q2. 加速库加载失败**
先确认 `native/prebuilt/libsatstream.so` 与板端架构一致：
`file native/prebuilt/libsatstream.so` 应显示 `ARM aarch64`。
不一致时在板端重新编译。

**Q3. 温度降频**
连续跑满 4 核时，树莓派 4B 会因温度降到 1.5 GHz 以下，帧率下降 10%~20%。
加散热片/风扇，或用 `--max-cells 4` 降低持续负载。

**Q4. 内存占用**
6 图块配置下峰值约 120 MB（含 ORT 运行时）。若板端内存紧张，
把 `--max-cells` 降到 4，或换 320 输入的小模型（本包默认即是）。
